# 📅 Planner

Um calendário inteligente de tarefas inspirado no Todoist, desenvolvido com HTML, CSS e JavaScript. O sistema permite organizar compromissos e atividades em visualizações semanais e mensais, utilizando prioridades e organização visual para aumentar a produtividade.

---

## 🚀 Funcionalidades

* 📆 Visualização mensal e semanal
* ✅ Criação e gerenciamento de tarefas
* 🔥 Sistema de prioridades
* 🎨 Identificação visual por cores
* 📝 Edição e remoção de tarefas
* 📌 Organização prática e intuitiva
* 💾 Salvamento local das tarefas
* 🌙 Interface moderna e responsiva

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 🎯 Objetivo do Projeto

O objetivo do projeto é oferecer uma forma simples, visual e eficiente de organizar tarefas e compromissos, utilizando um sistema de calendário integrado com gerenciamento de prioridades.
